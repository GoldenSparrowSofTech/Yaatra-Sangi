# Yaatra-Sangi (यात्रा संगी)

**Yaatra-Sangi** is your trusted travel companion platform designed to simplify itinerary planning, discover destinations, and enhance travel experiences.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- Git

### Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/GoldenSparrowSofTech/Yaatra-Sangi.git
cd Yaatra-Sangi
```
